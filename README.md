# Joseph John — Data Science Engineer Portfolio

A modern, high-performance portfolio website built with **TanStack Start**, **React**, and **Tailwind CSS**. This project showcases the work, skills, and certifications of Joseph John, a Data Science Engineer specializing in Machine Learning, NLP, and LLM applications.

## 🚀 Features

- **Modern UI/UX**: Clean, minimal, and responsive design focused on readability and professional presentation.
- **Interactive Background**: Dynamic particle system for an engaging landing experience.
- **Project Showcase**: Detailed list of machine learning and data science projects with technology tags.
- **Skills Matrix**: Organized categorization of technical expertise from programming to AI/NLP.
- **Responsive Design**: Optimized for all screen sizes, from mobile devices to large desktop monitors.
- **High Performance**: Built on TanStack Start for lightning-fast navigation and SEO optimization.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React framework)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [tw-animate-css](https://github.com/michaeltaranto/tw-animate-css)
- **Deployment**: [Cloudflare Pages](https://pages.cloudflare.com/) (configured via `@cloudflare/vite-plugin`)

## 📂 Project Structure

- `/src/routes/index.tsx`: Main page content and component definitions.
- `/src/components/`: Reusable UI components.
- `/src/styles.css`: Global styles and Tailwind configuration.
- `/public/`: Static assets.

## 🏁 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Mimieamichy/jayjohn-portfolio.git
   cd jayjohn-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
